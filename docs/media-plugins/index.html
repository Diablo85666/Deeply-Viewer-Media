Deeply Viewer Media Plugins

These optional packs provide web, video, and audio media support. Deeply Viewer asks before downloading, verifies the exact archive size and SHA-256 pinned by that viewer build, then installs it in the local media folder.

For in-viewer installation, use Scarica plugin in the Media settings. Manual downloads are provided for inspection and troubleshooting.
