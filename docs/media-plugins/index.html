Plugin multimediali di Deeply Viewer

Questi pacchetti opzionali forniscono supporto per contenuti web, video e audio. Deeply Viewer chiede il consenso prima del download, verifica dimensione e SHA-256 esatti previsti da quella versione del viewer, quindi installa i file nella cartella multimediale locale.

Per installare i plugin dal viewer, usa Scarica plugin nelle impostazioni Media. I download manuali servono per verifiche e diagnosi.
